# Icon-Entwürfe vom 2026-09-02

Gemeinsame Vorgaben:

- blauer historischer Doppeldecker fast frontal, Propeller zum Betrachter
- Flugzeug in der Bildebene etwa 45 Grad im Uhrzeigersinn gedreht; die Tragflächen
  verlaufen von links oben nach rechts unten
- fast vollständige Ausnutzung der sicheren Icon-Diagonale
- glaubwürdige Tragflächenbespannung, Rippen, Streben, Verspannung, Sternmotor,
  Nabe, Propeller und Fahrwerk statt pillenförmiger oder aufgeblasener Flächen
- einfache, auch klein erkennbare Gesamtsilhouette ohne Text, Rahmen oder Szenerie

Varianten:

- `01-kupferorange.png`: Kobaltblau auf gedämpftem echtem Kupferorange als
  direktem Komplementärkontrast; flächiger Hintergrund.
- `02-graphit-kupferakzent.png`: Kobaltblau auf Graphit; Kupferorange nur als
  radialer Gegenakzent hinter dem Flugzeug.
- `03-dunkelbronze.png`: Ultramarin auf dunklem, entsättigtem Bronzebraun;
  ruhiger Hintergrund ohne zusätzliches Zeichen.
- `04-hellgrau-kupferkante.png`: Kobaltblau auf kühlem, ausdrücklich nicht
  gelblichem Steingrau; Kupferorange nur als schmale Trennkante.
